Задание 04

Слайд-шоу

Условие

Создайте интерактивное слайд-шоу с переключением изображений. Реализуйте навигацию с помощью кнопок «Назад» и «Вперед», а также добавьте индикаторы для быстрого перехода к нужному слайду.

Консоль v.1.0
FILE 01: Платы и микросхемы. Здесь рождаются идеи.
FILE 02: Тёмные коридоры и хардкорные испытания.
FILE 03: Наброски. Попытка сохранить рассудок.
